# Lucknow Atlas

**Lucknow Atlas** is an interactive heritage and tourism map of Lucknow, Uttar Pradesh.

It brings together major monuments, historic buildings, religious sites, cultural areas, parks, and other notable places across the city in a visual, mobile-friendly map.

The goal is to make exploring Lucknow easier than browsing through long lists of attractions. Each location can be opened directly from the map to view photographs, basic information, and its geographic location, with quick access to directions.

## Features

- Interactive map of Lucknow landmarks and heritage sites
- Photo-based map markers
- Search with place suggestions
- Category filtering
- Nearby places using browser location
- Individual place details
- Image galleries and lightbox
- Google Maps directions links
- Responsive desktop and mobile interface
- Vector basemap with detailed roads, parks, water, and labels
- Locally hosted landmark photographs
- No heavy frontend framework or build system required

## Map Stack

- **Leaflet** — map interaction and UI logic
- **MapLibre GL JS** — vector basemap rendering
- **MapTiler Streets** — current basemap
- **OpenStreetMap data** — geographic foundation

The project keeps the existing Leaflet interaction model while using MapLibre for modern vector map rendering.

## Purpose

Lucknow has a large number of historically and culturally significant places spread across the city, including many locations that receive much less attention than the major tourist attractions.

Lucknow Atlas is intended to provide a simple visual way to discover these places and understand where they are in relation to one another.

## Current Status

The project is currently non-commercial and is being developed as an independent public mapping project.
